# ADR-002 - Definição da linguagem e do framework

- **Data:** 26/11/2026
- **Status:** Aceita
- **Responsável:** Ítalo Martins de Deus

## Contexto

O back-end do Tech Challenge precisa utilizar uma linguagem e um framework que permitam desenvolver o MVP com segurança, qualidade e prazo adequado.

Além da capacidade técnica das ferramentas, a definição considera a experiência profissional disponível, a familiaridade com as tecnologias e a maturidade do ecossistema.

## Decisão

Para este projeto, adotamos **Java** como linguagem de programação e **Spring Boot** como framework principal do back-end. A implementação seguirá essa definição.

A escolha se baseia nos seguintes fatores:

- Java e Spring possuem ampla maturidade e são utilizados há muitos anos no mercado;
- Há experiência profissional e familiaridade prévias com a linguagem e o framework;
- Essa experiência reduz riscos e permite concentrar esforços no domínio da oficina e na arquitetura da solução;
- O ecossistema oferece recursos consolidados para APIs, segurança, persistência, testes e documentação;
- São tecnologias confiáveis e adequadas para a manutenção e evolução do sistema.

## Consequências

### Positivas

- Maior produtividade durante o desenvolvimento;
- Redução do tempo de aprendizado e de configuração;
- Menor risco de decisões equivocadas por falta de experiência;
- Facilidade para encontrar documentação, exemplos e suporte;
- Boa base para evolução do projeto após o MVP.

### Negativas

- A solução pode exigir mais configuração inicial do que alternativas mais leves;
- O código pode ser mais detalhado do que em algumas linguagens alternativas.

## Alternativas consideradas

Foram consideradas outras linguagens e frameworks. Java e Spring Boot foram escolhidos porque a experiência existente com essas tecnologias reduz riscos e favorece a entrega do MVP.

A maturidade das tecnologias e a confiabilidade do ecossistema reforçam a escolha para este projeto.
